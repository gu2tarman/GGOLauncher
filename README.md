# GGO Launcher

GGO Custom Edition 전용 런처. Tauri 2 (Rust + React + TypeScript) 기반 단일 실행 파일.

## UO 버전 선택

프로필의 클라이언트 버전을 비우면 자동 모드입니다. PLAY 또는 MULTI LOGIN을 누를 때 UO 설치 폴더의 `client.exe` 버전을 다시 읽어 CE의 `-clientversion` 인자로 전달합니다. 직접 입력한 버전은 자동 감지보다 우선합니다. 자동 감지 실패 시에는 이전 CE 설정으로 실행하지 않고 경로 확인 또는 직접 입력을 안내합니다.

## 프로필 가져오기

1. CE와 사용할 보조 프로그램을 먼저 설치하고 런처에 경로를 등록합니다.
2. **프로필 관리 → 프로필 가져오기**에서 CUO, RE 또는 CA를 선택합니다.
3. 기존 프로그램의 설치 폴더와 가져올 대상 설치 폴더를 지정합니다. 원본과 대상은 서로 다른 폴더여야 합니다. 보조 프로그램을 이미 같은 경로에서 사용한다면 기존 설정을 공유하므로 복사할 필요가 없습니다.
4. 항목 검색 후 필요한 캐릭터·프로필·파일만 선택합니다. RE의 스크립트 목록과 실제 스크립트 파일은 각각 선택합니다. 설치 폴더 밖에 연결된 파일은 **외부 참조 스크립트** 그룹에 표시됩니다.
5. 기존 항목을 교체하려면 교체 옵션을 선택합니다. 기본값은 기존 유지이며 CA는 파일 전체가 아니라 선택한 설정 항목별로 적용합니다.
6. 미리보기의 대상 파일과 경로 안내를 확인하고, 게임 및 RE·CA를 종료한 뒤 **선택 항목 가져오기**를 누릅니다.
7. CE에는 기존과 같은 계정·서버·캐릭터로 접속합니다. RE·CA에서는 가져온 프로필을 선택하고 창 배치·핫키·스크립트 실행을 확인합니다.

| 종류 | 지원하는 항목 |
|---|---|
| CUO | `Data/Profiles`의 계정/서버/캐릭터별 JSON·XML, 공통 프로필 JSON·XML. 사용자 지정 `profilespath` 지원 |
| RE | `Profiles/<이름>/RazorEnhanced.settings.*` 형식의 일반 설정·핫키·SCRIPTING·에이전트 설정, Scripts·Macros, 외부 참조 파일 |
| CA | `Profiles/*.json`의 설정 항목별 병합, Macros·Modules의 사용자 파일, 외부 참조 파일. `Assistant.json`의 사용자 지정 저장 폴더 지원 |

새 RE 프로필은 필수 GENERAL 설정과 `RazorEnhanced.NewProfiles` 등록도 함께 처리합니다. 대상의 기존 프로필·마지막 선택·캐릭터 연결을 유지하고 새 프로필 연결만 추가합니다. CA의 캐릭터 자동 연결과 로그인 정보는 복사하지 않으므로 CA에서 프로필을 선택해주세요. 실행 파일, DLL, 로그인/비밀번호 파일, 백업·캐시는 이관하지 않습니다. 스크립트 내부의 고정 경로와 연결 목록에 없는 별도 모듈은 자동 분석하지 않습니다.

백업은 `%APPDATA%/GGOLauncher/import-backups/import-<번호>/`에 저장합니다. `manifest.json`에 대상 경로와 전후 SHA-256이 있으며, `N.bak`는 원래 내용, `N.new`는 가져온 내용입니다. 오류 시 이번 작업의 변경을 자동 복구합니다. 완료 후 직접 되돌릴 때는 게임을 종료하고 manifest의 대상에 해당 `.bak`를 복사합니다. 백업 값이 null인 항목은 새로 생성된 파일이며, 이후 수정 내용이 없는지 전후 해시를 확인한 뒤 처리해야 합니다.

현재 지원하는 RE 저장 형식 이외의 구형 단일 XML/이진 프로필이나 모든 스크립트 의존성의 자동 변환을 보장하지 않습니다. 저장 형식과 개별 게임 동작은 이관 후 확인해주세요.

## 개발 실행

```powershell
npm install
npm run tauri dev
```

## 릴리스 빌드

```powershell
npm run tauri build
```

산출물: `src-tauri/target/release/GGOLauncher.exe`

## 프로젝트 구조

```
src/              프론트엔드 (React + TS)
src-tauri/        백엔드 (Rust)
public/           정적 자산 (로고 등)
```
